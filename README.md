# Cove

Cove is a concept for a wave-powered offshore station that could recharge autonomous underwater vehicles (AUVs) and support repeated inspection missions. This repository contains **screening simulations, concept CAD, and a prototype plan**. It does not yet contain measured full-scale power output or autonomous AUV docking results.

- [Architecture, assumptions, and scaling](ARCHITECTURE_AND_SCALING.md)
- [Business analysis and customer questions](BUSINESS_ANALYSIS.md)
- [Two-week physical MVP plan](HOW_TO_BUILD_THE_MVP.md)
- [Good Bull pitch plan and display model](pitch/GOOD_BULL_2026.md)
- [Generated simulation results](RESULTS.txt)

The current Cove-S concept uses relative motion between a surface hull and submerged reaction body to drive a generator. The printed internal-mass prop in the pitch folder illustrates an earlier idea and is not a working generator or a model of the current architecture.
