Piezo sheet: customizable cell size and number of cells

Strip model per cell · N identical cells · shared source (one pump split across cells) or independent jets (upper bound)
Laminate, load, damping & charging assumptions
Each cell is a clamped PZT-5A/steel strip struck at its tip by a pulsed jet (MODEL.md). Cells feed separate loads; totals are sums of per-cell AC power. Shared mode divides the source area evenly: per-cell jet diameter = source ÷ √N.
Sources: model.mjs, sheet.mjs (checked by node check.mjs, node check-sheet.mjs). Rebuild with node build.mjs.
