Proposed node: sealed pendulum → generator → battery → dock → AUV

Coupled screening model · regular waves · hull pitch + pendulum on the wave orbit · generator damping auto-matched · 24 h charge budget
Hull, pendulum, drive train, storage & dock assumptions
A horizontal cylinder floats like a log and follows the wave (pitch from the wave slope, surge/heave from the orbit). Inside, a physical pendulum on a transverse shaft lags the hull; the generator resists the relative rotation. A torsion spring (negative when needed) tunes the pendulum to the wave period with a long arm so it keeps a full stroke; end-stops bound the swing. Generator damping 0 = search for the power-maximising value. See MODEL.md for what is not modeled.
Source: node-model.mjs (checked by node check-node.mjs). Rebuild with node build.mjs; sweeps in RESULTS.md via node run.mjs.
